# M1 — Voice, chat, interview, router, triage

- Edit only `web/src/{voice,screens/ChatScreen*,components/MicInput*,components/CameraCapture*}`, `server/src/{interview,router,triage}/`, `server/src/modules/{crop_doctor,livestock}/`, `data/{interview,triage}/`.
- Typed box and chips must always be visible; voice is never the only path.
- The LLM may ONLY emit feature ids from `catalog.feature_vocab`; anything else is dropped.
- Red flags are evaluated before scoring; any livestock red flag → `vet_now`.
- Catalog entries without `advisory_source` produce no treatment steps.
- Land units always go through `units.ts` and are confirmed with the farmer.
